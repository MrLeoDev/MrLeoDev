## About me

I'm a software developer focused on turning complex business rules into reliable, understandable applications.

PHP and Laravel are the technologies I work with most today, but I don't define myself by a single language. What interests me most is understanding a problem, designing the right solution and carrying it through from analysis to delivery.

I particularly enjoy work involving:

- 🧩 Complex business logic and domain rules
- 🗃️ Data modelling, SQL and data-heavy workflows
- 🔌 APIs and integrations between systems
- ⚙️ Backend architecture and maintainable application design
- 🧪 Debugging, testing and improving existing systems
- 🚀 Taking ownership of a feature from requirement analysis to production-ready implementation

## How I like to work

I value code that solves the real problem without becoming unnecessarily complicated. I like understanding the business context behind a feature, challenging unclear requirements when needed, and keeping solutions readable for the next developer who has to work on them.

I'm also comfortable working independently: investigating an issue, discussing the functional need, designing the implementation, testing it and following it through to completion.
